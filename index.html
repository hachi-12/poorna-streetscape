GitHub Pages Deployment & VR Setup

Host your own Enscape 360 panoramas for Meta Quest WebVR

Exporting from Enscape

Export your architectural renders as 360 Panorama (Equirectangular PNG/JPG) at 4096x2048 resolution for optimal performance on Meta Quest headsets.

Deploying to GitHub Pages

  1. Create a new repository named poorna-market-vr on GitHub.
  2. Upload this index.html file along with your exported 360 images.
  3. Go to Settings > Pages, select main branch and click Save.
  4. HTTPS URL will be generated automatically (Required for Meta Quest WebXR APIs).

Viewing on Meta Quest

Open the Meta Quest Browser in your VR headset, navigate to your GitHub Pages URL, and click the "Enter VR" button at the bottom right corner.
